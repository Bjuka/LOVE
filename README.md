# ✦ MY LOVE — A Forever Sanctuary ✦

An aesthetic, interactive digital sanctuary and memory keepsake built with love.

---

## ✨ Features

- **📸 Customizable "Favorite View":** Dynamic hero card with custom polaroids, badges, and love notes.
- **🫂 "For When You Feel Low" Uplifting Hub:**
  - **Instant Warm Hug:** A calming breath animation, ambient glow, and reassuring reminder.
  - **Wholesome Reminder Deck:** An interactive card deck with random sweet affirmations.
- **🏡 Interactive Dream Board:** Visual vision board for future goals, milestones, pets, and dreams.
- **🎞️ Our Memory Box:** Chronological keepsake gallery with photos, tags, and date badges.
- **🎶 Cozy Music Hub:**
  - **Ambient Lofi Chimes:** Procedural, relaxing audio synthesizer built with Web Audio API.
  - **Custom Playlist Queue:** Dedicated player for personal `.mp3` tracks with progress scrubbing and volume control.
- **🔗 Read-Only Snapshot Link Generator:** Generates a clean URL query snapshot that hides all edit and delete buttons for sharing.
- **💖 Particle Bursts:** Interactive floating heart canvas and confetti effects on tap.

## 🚀 Running Locally

1. Clone or download the repository:
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/<repo-name>.git
   ```
2. Start a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   ```
3. Open your browser and navigate to:
   ```text
   http://localhost:8000
   ```

---

## 🌐 Deploying to GitHub Pages

1. Push all files (`index.html`, `style.css`, `script.js`, and `.mp3` files) to your repository on the `main` branch.
2. In your repository, go to **Settings** → **Pages**.
3. Under **Branch**, select `main` and root `/`.
4. Click **Save**. Your site will be live at:
   ```text
   https://<your-username>.github.io/<repo-name>/
   ```
